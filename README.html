University Info Chatbot

RAG-чатбот, который скрейпит сайты университетов, индексирует их и отвечает на вопросы на основе актуальной информации. Интервал перескрейпинга настраивается через веб-интерфейс.

Архитектура

scraper/   — обход сайта, извлечение чистого текста (вежливый скрейпинг)
indexer/   — чанкинг, локальные эмбеддинги, векторная БД (ChromaDB), дедупликация
api/       — FastAPI: /ask (RAG), /universities, /settings, /scrape, /health
ui/        — веб-интерфейс: чат + настройка интервалов скрейпинга
config/    — universities.yaml (университеты, интервалы, параметры моделей)
data/      — база векторов и хэши страниц (создаётся автоматически)

Быстрый старт (локально)

cd university_chatbot
pip install -r requirements.txt

# Ollama должен быть запущен с моделью генерации:
ollama pull qwen2.5-coder:7b

# запуск
python -m api.main

Открой http://localhost:8000/ui — чат и настройки.

Docker

docker compose up -d --build

API

Метод Путь Что делает
GET /health проверка живости
GET /universities список университетов + интервалы
POST /settings изменить интервал скрейпинга ({"university","scrape_interval_days"})
POST /scrape ручной скрейп ({"university"})
POST /ask вопрос ({"question","university?"}) → ответ + источники

Как добавить университет

  1. Открой config/universities.yaml
  2. Добавь блок (скопируй существующий)
  3. Перезапусти сервис — университет появится в UI.

Особенности

  • Локальные эмбеддинги (sentence-transformers) — без внешних API-затрат
  • Локальная генерация (Ollama) — данные не уходят в облако
  • Дедупликация по хэшу: повторные скрейпы не задублируют страницы
  • Ответы только из контекста; если нет данных — бот честно скажет «не знаю»
